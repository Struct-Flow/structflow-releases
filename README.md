# structflow-releases

StructFlow AutoCAD eklentisinin **dağıtım deposu**. Kaynak kod burada değildir;
bu repo yalnızca sürüm release'lerini barındırır (her release'te `manifest.json`
+ payload zip'i asset olarak bulunur).

Kurulum: `StructFlow-Setup-<sürüm>.exe`'yi çalıştırın — sunucu alanı bu repoyu
(`github:Bortigoat/structflow-releases`) gösterir, erişim anahtarı gerekmez.
Yayınlama: kaynak repodaki `tools\publish-github.ps1`.
